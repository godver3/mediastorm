Quality presets

Rank and filter releases with Sonarr/Radarr quality profiles and custom formats, imported from TRaSH-Guides, from a Sonarr/Radarr instance or written by hand. When a preset is active it replaces the simple ranking and filtering settings for that media type.

Advanced Meant for people who know Sonarr/Radarr quality profiles and custom formats. The simple ranking under Search & quality is enough for most setups; nothing here is active until you select a preset.

Anime titles (genre Anime, or Animation from Japan, China or Korea) use the anime presets first, on every level (device, profile, server), then the normal ones. Presets marked anime only fit only anime slots, presets marked everything but anime only normal slots. While a preset ranks, the anime language preference from Search & quality is not used: anime presets bring their own language formats.

A title or episode one of the profile's local libraries has plays from there: Library copy is offered first in version pickers and used by default, in every app and in Jellyfin (Continue watching too). Picking another preset for the title streams it instead, also later.

Offer in version pickers

Checked presets appear as extra versions ("Preset · name") in the version menu of Jellyfin clients and in the web player's release list, so viewers can pick one for a single playback. They can always be picked, even with the option above off.

Presets marked anime only appear only on anime, presets marked everything but anime never on anime.

Order of precedence: per-search choice → for anime titles the anime slots (device → profile → the anime presets above) → device → profile → the presets above. These checks always run first because they protect correctness or an explicit audio choice:

Add a preset

Profiles and devices with their own preset keep it. New TRaSH and Sonarr/Radarr presets follow upstream changes automatically; change that under Sync.

The preset keeps the instance URL and API key so it can follow later changes made there.

Accepts a preset exported from mediastorm, a TRaSH profile with its custom formats ({"profile": …, "customFormats": […]}), or a list of custom formats exported from Sonarr/Radarr.
