Integrations
Watch Activity & Sync

Connect Trakt, Simkl, MDBList, and self-hosted Scrob accounts for watch activity and history sync. Watched items can be sent to a linked service; use a sync automation when you want to pull history into MediaStorm.

Trakt

Create an app at developer.trakt.tv/apps (Trakt asks you to link GitHub once before your first app) and copy its Client ID. Add urn:ietf:wg:oauth:2.0:oob as a Redirect URI. Apps created since October 2026 have no Client Secret; leave that field empty unless your app is older and shows one.

Add New Trakt Account

Waiting for authorization...

Go to trakt.tv/activate and enter code:

Simkl

Create an app at simkl.com/settings/developer/new and copy the Client ID. For a new app pick the TV, devices & command line client type; older (AUTH V1) apps keep working. Sign-in uses Simkl's code flow, so no redirect is needed.

Add New Simkl Account

Only the Client ID is needed: Simkl's code sign-in doesn't use a Client Secret. Choose the "TV, devices & command line" client type when Simkl asks.

Authorize Simkl

Copy this code, then open Simkl authorization and enter it:

Scrob (self-hosted)

Enter your Scrob instance URL and user API key. Username/password are optional for imports, but required for Local → Scrob writes. For a 2FA-enabled account, also enter its Base32 TOTP secret or full otpauth URI so scheduled tasks can generate fresh codes.

Add Scrob Account

This is the reusable seed shown when enabling 2FA, not the rotating six-digit code. It is stored as a write-only secret.

MDBList

Get an API key from mdblist.com/preferences.

Add New MDBList Account

Profile Service Links

Link each profile to Trakt, Simkl, MDBList, and/or self-hosted Scrob. When a profile watches content, it will automatically scrobble to its linked services (one-way push). To sync history in either direction, use the corresponding History Sync automation.

Plex Accounts

Register Plex accounts and link them to profiles for watchlist imports and Plex library playback progress. Unlinked profiles do not report playback to Plex.

Jellyfin Bridge

Serve a Jellyfin-compatible server so Jellyfin apps (web, Android, Android TV, Swiftfin, Findroid, Plezy, ...) can sign in with a profile name and the account password, browse and play. Signed-in apps are listed under Jellyfin devices.

Runs the bridge listener. Turning it off stops it at once and closes the port; signed-in apps stay signed in for when it is back.

Test

Checks the bridge the way a Jellyfin app connects to it, and whether its address is reachable (from this browser, or from the server when this page is on HTTPS and the address is plain HTTP). Enter a profile name (or account/profile) and the account password to test signing in too; the test session is signed out afterwards.

The address Jellyfin apps use. Leave empty for this host and the bridge port.
